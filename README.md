## 🚀 تشغيل المنصة محلياً

1. **عبر XAMPP Apache:**
   - ضع المجلد داخل `c:/xampp/htdocs/host`
   - شغل Apache في لوحة XAMPP وافتح: `http://localhost/host/`

2. **عبر أي خادم محلي:**
   ```bash
   python -m http.server 8080
   ```
   ثم افتح: `http://localhost:8080/`
